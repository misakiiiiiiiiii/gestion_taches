# Application Python de Gestion des Tâches

## Description
Application console simple en Python pour gérer une liste de tâches quotidiennes[cite: 1].

## Fonctionnalités
1. **Ajouter une tâche** : Permet d'ajouter une tâche (rejet des saisies vides)[cite: 1].
2. **Afficher les tâches** : Affiche la liste complète des tâches numérotées[cite: 1].
3. **Rechercher une tâche** : Permet de filtrer les tâches par mot-clé[cite: 1].
4. **Quitter** : Ferme l'application[cite: 1].

## Méthode d'exécution
1. Ouvrir le dossier du projet dans **VS Code**[cite: 1].
2. Ouvrir le fichier `main.py`[cite: 1].
3. Cliquer sur le bouton **« Run Python File »** en haut à droite de l'écran dans VS Code, ou exécuter la commande suivante dans le terminal :
   ```bash
   python main.py
